# AitherFiles

AitherFiles is a lightweight, mobile-friendly browser file manager for AitherForge.

## Features

- Clean Aither-style dark interface
- Responsive layout for iPhone, tablet, and desktop
- Upload files by picker or drag and drop
- Search and sort files
- Recent, favorites, images, and documents filters
- Create folders
- Favorite files
- Local browser metadata storage with `localStorage`
- No backend or API key required
- GitHub Pages compatible

## Privacy

This version does not send selected files to a server. File metadata is stored locally in the browser. The browser file picker controls access to the actual files.

## Run

Open `index.html` in a browser or publish the repository with GitHub Pages.
